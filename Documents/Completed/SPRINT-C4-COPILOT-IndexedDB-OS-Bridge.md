## Context

The OS desktop (dist.html) currently runs as a srcdoc iframe inside
capstone.html with `sandbox="allow-scripts allow-same-origin allow-forms
allow-modals"`. The `allow-same-origin` flag means the OS iframe shares the
same file:// origin as capstone.html — and therefore the same IndexedDB.

Right now the OS has no knowledge of who the student is. It reads its own
localStorage for theme/window state, but gets bug configuration via a
`localStorage['qa-capstone-activeBugs']` key that capstone.html writes.

This sprint replaces that bridge with a clean IndexedDB integration:
- `js/db.js` is bundled directly into the OS
- The OS reads the student session (caseId, role, bug toggles, scenario) from
  IndexedDB on boot instead of relying on localStorage hacks
- The OS writes capstone results directly to IndexedDB, so capstone.html
  only needs to redirect on completion (not save data)
- capstone.html adds a proper lesson-completion gate before launching the OS

Stack: pure HTML/CSS/JS, no modules, no imports. All functions are globals.

## Deliverable 2: desktop/src/os-core.js — Boot from IndexedDB

### 2a. Add a capstone session constants block near the top of os-core.js

After the `STORAGE_KEY` constant, add:

```javascript
// Key written to localStorage by capstone.html just before launching the OS.
// Tells the OS which student is running the session so it can query IndexedDB.
// When running dist.html standalone (no capstone), this key is absent and
// the OS boots normally with default state — no crash.
const CAPSTONE_SESSION_KEY = "qa-capstone-session";
```

### 2b. Replace the localStorage activeBugs bridge in loadState()

Find the block that reads `qa-capstone-activeBugs` (added in a previous
sprint). Replace it entirely with the new IndexedDB-based boot sequence:

```javascript
// ── CAPSTONE SESSION BOOT ─────────────────────────────────────────────
// When the OS is launched from capstone.html, a session object is written
// to localStorage before the iframe is created. Read it here and use it
// to load the student's configuration from IndexedDB synchronously.
// If absent (standalone dist.html), skip gracefully.
(function loadCapstoneSession() {
  try {
    var raw = localStorage.getItem(CAPSTONE_SESSION_KEY);
    if (!raw) return;   // standalone mode — nothing to load
    var session = JSON.parse(raw);
    if (!session || !session.caseId) return;

    // Store caseId so other functions can use it (e.g. to write results)
    state.capstoneCaseId   = session.caseId;
    state.role             = session.role || state.role;
    state.activeScenarioId = session.scenarioId || "capstone-001";
    state.capstoneScenarioId = state.activeScenarioId;

    // activeBugs: convert the { bugId: true/false } toggle map to an
    // array of enabled bugId strings (what state.activeBugs expects).
    if (session.bugToggles && typeof session.bugToggles === 'object') {
      state.activeBugs = Object.keys(session.bugToggles).filter(function(k) {
        return session.bugToggles[k] === true;
      });
    }
  } catch (e) {
    console.warn("os-core: could not load capstone session", e);
  }
})();
```

### 2c. Write capstone results directly to IndexedDB on Submit

Find the `handleSubmit()` function (or wherever `CAPSTONE_COMPLETE` is
posted). After evaluating the score, write it to IndexedDB before posting
the message:

```javascript
// Write results directly to Academy IndexedDB if we have a caseId.
// This means capstone.html only needs to listen for the signal to redirect
// — it no longer needs to call saveQuizResults() or awardCertificate().
if (state.capstoneCaseId && typeof initDB === 'function') {
  initDB()
    .then(function() {
      return saveQuizResults(state.capstoneCaseId, 'capstone', {
        score:       result.score,
        maxScore:    result.maxScore,
        percentage:  result.percentage,
        passed:      result.passed,
        completedAt: new Date().toISOString()
      });
    })
    .then(function() {
      return awardCertificate(state.capstoneCaseId);
    })
    .catch(function(err) {
      console.warn("os-core: failed to write capstone results to IndexedDB", err);
    });
}
```

## Deliverable 3: capstone.html — Session handoff + lesson gate

### 3a. Write a full session object to localStorage before launching the OS

In `initCapstone()`, replace the existing `localStorage.setItem` for
`qa-capstone-activeBugs` with:

```javascript
// Write the full session object so the OS can boot with correct context.
// activeBugState is a { bugId: true/false } map from getBugToggles().
try {
  var session = {
    caseId:      currentSession.caseId,
    role:        currentSession.role  || 'junior',
    scenarioId:  'capstone-001',
    bugToggles:  activeBugState       || {}
  };
  localStorage.setItem('qa-capstone-session', JSON.stringify(session));
} catch (e) {
  console.warn('capstone.html: could not write session to localStorage', e);
}
```

### 3b. Add a lesson-completion gate before calling initCapstone()

In the `.then()` block that calls `initCapstone()`, add this check first:

```javascript
// Gate: ensure the student has completed all prerequisite lessons.
// Without this check, a student could navigate directly to capstone.html
// via the browser address bar and bypass the entire course.
var lessonsComplete = (currentProgress && currentProgress.lessonsComplete) || [];
var assignedPath    = (currentProgress && currentProgress.placementSurvey)
                      ? currentProgress.placementSurvey.recommendedPath || []
                      : ['lesson-1', 'lesson-2', 'lesson-3', 'lesson-4'];

var requiredLessons = assignedPath.filter(function(id) {
  return id !== 'capstone';
});
var allComplete = requiredLessons.every(function(id) {
  return lessonsComplete.includes(id);
});

if (!allComplete) {
  showToast('Complete all lessons before starting the Capstone.', 'error');
  setTimeout(function() {
    window.location.href = 'course.html';
  }, 2500);
  return;
}
```

### 3c. Simplify handleOSMessage()

Since the OS now writes results to IndexedDB directly, capstone.html only
needs to receive the signal and redirect. Update `handleOSMessage()`:

```javascript
function handleOSMessage(event) {
  var msg = event.data;
  if (!msg || msg.type !== 'CAPSTONE_COMPLETE') return;

  // The OS has already written results to IndexedDB.
  // Clear the session key so the next OS load starts clean.
  try { localStorage.removeItem('qa-capstone-session'); } catch (e) {}

  // Small delay so the OS score modal can display before we navigate away
  setTimeout(function() {
    window.location.href = 'certificate.html';
  }, 2000);
}
```
