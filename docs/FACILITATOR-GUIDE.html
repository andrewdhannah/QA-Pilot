1. Welcome & Overview

QA Pilot is a professional, offline training platform designed to bridge the gap between theoretical knowledge and practical application for junior QA analysts.

QA Pilot trains junior QA analysts to:
  • Identify defects in a simulated CRM (Dynamics)
  • File structured bug reports in a simulated ADO tracker
  • Reference acceptance criteria correctly
  • Work within role-appropriate permissions

The platform runs entirely offline in a browser. No installation, no accounts, and no internet connection are required.

2. Trainer Workflow

Depending on the stage of training, you will direct trainees to use the platform in one of two modes:

Training Mode (Guided Learning)

  1. Trainee opens index.html in their browser.
  2. Trainee logs in (any name — login is not verified).
  3. Trainee completes Lessons 1–5 in order.
  4. Trainee opens the Training app inside the OS (dist.html) to perform guided practice.

Assessment Mode (Scored Capstone)

  1. Trainee completes all lessons first.
  2. Trainee opens capstone.html (Beginner) or capstone-2.html (Advanced).
  3. Trainee works through the scenario in the OS simulator.
  4. Trainee clicks "Submit for Certification".
  5. The final result is written to the browser's local storage and displayed on a certificate page.

3. Reviewing Results

Because the platform is offline, all results are stored in the browser's IndexedDB (local database). To review trainee performance:

1. Open dist.html
2. Open the Reports app from the desktop
3. Select a trainee session to see: score, pass/fail, bugs found, bugs missed, and report quality.

Note: Results are stored per-browser-per-device. If a trainee clears their browser cache or switches computers, their previous results will not appear in the Reports app.

Points are awarded as follows:

  • 1 pt: Bug correctly identified in the CRM.
  • 1 pt: Complete ADO report filed (Title, Severity, Steps).
  • 1 pt: Correct AC reference included in the report.

6. Known Limitations

  • Storage: Results are stored in the browser only — not synced to a central server.
  • Data Loss: If a trainee clears browser data, results are lost.
  • Browser Support: Optimized for Chrome and Edge. Firefox and Safari may have minor visual differences.
  • Customization: The Training app step-through is hardcoded; custom scenarios require developer modification.
  • Analytics: The Reports and Inspector apps provide raw data only; advanced analytics are not yet implemented.

7. Troubleshooting

Issue Fix
OS simulator is blank / not loading Ensure you are opening dist.html, not index.html.
Apps won't open when double-clicked Try a second double-click; if still stuck, refresh the page.
Score not showing after Submit Verify the trainee reached the "Submit" button inside the OS, not the browser back button.
Lesson marked incomplete Lessons must be completed in order. Ensure the quiz was submitted before proceeding.
Two navigation bars stacked (Lesson 4) This was fixed in V1. Ensure you are using the latest build.
